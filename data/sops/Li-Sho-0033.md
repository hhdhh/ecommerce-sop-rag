# Shopee Listing 标题与五点描述 SOP

> 适用范围：Shopee Listing 优化 业务
> 责任人：陈晨（Listing 优化组）
> 评审：周更

## 标题结构

1. 品牌名 + 核心关键词 + 属性词 + 适用场景 + 容量/规格
2. 字符限制：100 字符
3. 禁止堆砌：同一关键词最多出现 2 次
4. 禁止使用：best、#1、guaranteed 等绝对化用词

## 五点描述

每点 200 字符以内，按以下顺序：
1. 核心卖点（材质/工艺）
2. 使用场景（解决什么问题）
3. 差异化优势（对比同行）
4. 包装清单
5. 售后承诺

## A+ 页面布局

- 模块 1：品牌故事 + 高对比场景图
- 模块 2：3 张对比图（功能拆解）
- 模块 3：场景化使用流程图
- 模块 4：FAQ 模块（前 5 个常见问题）
- 模块 5：跨链接模块（关联 3 个互补品）

## 关键词策略

1. 核心词：搜索量 > 5000，置于标题前 80 字符
2. 长尾词：搜索量 500-5000，分布于五点描述
3. 竞品词：监控 top 20 ASIN 标题词频，差异化补全
4. 反查工具：Helium 10 / Jungle Scout / Cerebro

## 合规红线

- 禁用：未授权的品牌名、名人姓名
- 禁用：医疗/减肥/金融功效承诺
- 禁用：与图片不符的型号/参数
- 侵权自查：上架前 24h 用工具扫描商标局数据库
