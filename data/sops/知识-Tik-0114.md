# TikTok Shop 知识产权侵权申诉 SOP

> 适用范围：TikTok Shop 知识产权与合规 业务
> 责任人：王浩（知识产权与合规组）
> 评审：周更

## 收到投诉后 24h 行动

1. 拉取投诉邮件原文，记录：投诉方、投诉商标号、投诉理由、ASIN 清单
2. 内部初步判断：是否真侵权（核对自家产品供应链文件）
3. 真侵权：立即下架 + 库存处理（销毁 / 改包装）
4. 假投诉 / 恶意投诉：进入申诉流程

## 申诉材料准备

- 商标查询截图（USPTO / 当地商标局）
- 供应商授权链（采购合同 + 商标使用授权）
- 产品实拍图（与投诉方对比，证明不构成混淆）
- 历史销售记录（证明上架时间早于投诉方注册时间）
- 律师信（专业案件）

## 申诉信模板

尊敬的 TikTok Shop 团队：

我们就 [ASIN 列表] 被 [投诉方] 以 [商标号] 投诉侵权一案提出申诉。

事实与理由：
1. 我司 [商标号] 在 [国家] 已于 [日期] 注册，早于投诉方 [日期]
2. 我司产品采用 [自有设计]，与投诉方产品在 [外观 / 名称 / 功能] 上存在显著差异，不会造成消费者混淆
3. 附件：[证据清单]

请贵平台撤销本次投诉。如需进一步信息，请联系法务邮箱 legal@brand.com。

此致
[公司名] 法务部
[日期]

## 预防机制

- 新品上架前：商标库 + 外观专利库双查
- 监控：每周扫一次投诉高发关键词
- 供应链：要求供应商提供完整授权链文件
